Redbelly Social Cuts: clip pack review site

Open index.html in a browser. The page plays the six clips from the clips/ folder next to it, so keep the folders together.
For hosting, upload this whole folder to any static host (for example Vercel, GitHub Pages, Netlify or an S3 bucket).

clips/      01.mp4 to 06.mp4 (1080x1920, 30 fps) and the matching .srt subtitle files
posters/    one still frame per clip
clip_list   source episode, timestamp, speaker and post caption for each clip
verification.md   measured specs for every file
favicon.svg   browser tab icon

Fonts load from Google Fonts (Be Vietnam Pro, JetBrains Mono). Everything else is in this folder.
